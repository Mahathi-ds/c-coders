
# Project Overview

## 1. Introduction

This project is a C-based Natural Language Processing (NLP) library that provides a collection of functions for processing and analysing textual data.

The library implements fundamental NLP operations, allowing users to perform text preprocessing, convert textual documents into numerical representations, and apply basic text analysis and classification algorithms.

## 2. Objectives

The primary objectives of this project are:

- To implement commonly used NLP preprocessing operations in C.
- To provide reusable functions for text normalisation and tokenisation.
- To convert textual documents into numerical representations.
- To implement fundamental NLP algorithms.
- To provide a modular and reusable C library.

## 3. Features

### 3.1 Text Processing

- Text normalisation
- Sentence splitting
- Word tokenisation
- Case normalisation
- Stop-word removal
- Word frequency analysis
- N-gram generation
- Stemming

### 3.2 NLP Algorithms

- TF-IDF
- Cosine similarity
- Jaccard similarity
- Naive Bayes classification
- Sentiment scoring
- Keyword extraction
- Document similarity

## 4. Implementation Details

- Programming Language: C
- Compiler: GCC
- Header File: project.h
- Build System: Makefile
